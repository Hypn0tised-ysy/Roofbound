# 技能系统设计

技能分为 movement 和 utility 两类，每类只能选择一个技能，默认都为 null。
通过主界面的 Abilities button 进入技能选择界面，点击技能图标选择技能，点击已选技能图标取消选择。

## 1. 技能分类与选择规则

- movement 与 utility 独立选择，各自最多一个。
- 默认都是 null。
- 选择逻辑：
	- 点击未选中的技能图标 => 选中该技能并替换同类已选技能。
	- 点击已选中的技能图标 => 取消选择，回到 null。

## 2. 技能数据模型与持久化

- 运行时数据：
	- movementSkillId: string 或 enum
	- utilitySkillId: string 或 enum
- 持久化到 json（玩家选择写入 json）。
- 建议结构：
	```json
	{
		"movementSkillId": "DoubleJump",
		"utilitySkillId": "SlowTime"
	}
	```
- 读取时为空或未配置时视为 null。

## 3. 与现有移动系统的集成

### 3.1 状态机与运行时

当前 player 状态机包含 Grounded / OnPlatform / Airborne / PostSprint / Dead 等状态。
技能逻辑通过以下入口接入：

- Airborne 状态中处理二段跳与空中冲刺资格与消耗。
- Sprint/Jump runtime 计时器继续使用原有逻辑，但空中冲刺使用独立参数。
- 死亡状态下不允许技能生效。

### 3.2 输入层

- 空中冲刺：鼠标左键触发（只在空中允许）。
- 时间变慢：鼠标右键持续按下触发（按住有效）。
- 进入菜单时时间暂停（Time.timeScale=0），因此技能暂停。
- 死亡时保持时间继续流动，但技能不生效。

### 3.3 摄像机视效

- 空中冲刺触发 FOV 缩小效果（独立于地面冲刺）。
- 可在现有 sprint FOV 效果旁增加 “air dash FOV” 通道。

## 4. 技能行为规格

### 4.1 二段跳（Double Jump）

- 条件：仅在 Airborne 时允许一次额外跳跃。
- 消耗：每次离地后只能额外跳跃一次。
- 重置：落地（Grounded / OnPlatform）时重置次数。
- 冲突处理：如果同帧触发 jump + air dash，优先执行 jump。

### 4.2 空中冲刺（Air Dash）

- 触发：鼠标左键。
- 条件：仅 Airborne；每次离地允许一次。
- 参数：
	- airDashSpeed
	- airDashDuration
	- airDashCooldown
	- airDashFovDelta
- 行为：在 duration 内以固定速度推进；结束后进入冷却。
- 重置：落地时重置可用次数与冷却。

### 4.3 时间变慢（Slow Time）

- 触发：鼠标右键按住。
- 行为：按住时 Time.timeScale 降低，场景中生成TimeSlowVolume，将其volume的weight从0平滑增加到0.3。松开恢复。
- 菜单：进入任何菜单时 Time.timeScale = 0。
- 死亡：死亡后 timeScale 恢复为 1，但技能效果不生效。
- 参考参数：
	- slowTimeScale (如 0.2)
	- slowTimeFixedDeltaScale (fixedDeltaTime 同比例缩放)

## 5. 状态与冲突优先级

- Dead > MenuPause > SlowTime > AirDash > DoubleJump > Normal。
- AirDash 与 DoubleJump 同帧时优先 Jump，Dash 留到下一帧。
- 菜单打开时强制暂停所有技能与计时。

## 6. 设计验证清单

- 能否在空中完成二段跳？落地后是否重置？
- 空中冲刺是否独立于地面冲刺参数？FOV 是否正确触发？
- 右键按住是否触发慢动作，松开恢复？
- 菜单打开是否暂停时间？死亡是否恢复时间但技能无效？
- 技能选择是否写入 json 并在启动时恢复？
